Автосервис

Сейчас перенесём всю вашу базу — клиентов, визиты, фото и документы — на этот компьютер.
После этого приложение работает без интернета.

Чтобы поставить иконкой на рабочий стол: откройте меню браузера (три точки) → «Установить «Автосервис local»». Тогда приложение будет открываться отдельным окном.
