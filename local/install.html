Автосервис

Сейчас соберём приложение в один файл со всей вашей текущей базой внутри. Скачается на ваш компьютер — кладите куда удобно, открывайте двойным кликом.

Как пользоваться скачанным файлом: найдите autoservice.html в папке «Загрузки», перенесите на рабочий стол. Двойной клик — приложение открывается в браузере с локальным адресом file:///…. Всё работает без интернета, данные хранятся в этом файле и в браузере.
