# Автосервис · Картотека

Локальное веб-приложение для учёта клиентов автосервиса. Один HTML файл, без зависимостей и сборки.

## Запуск

Открыть `index.html` в Chrome (двойной клик).

## Что умеет

- **Карточки клиентов** — фамилия, имя, телефон, машина, гос. номер, заметки
- **История визитов** — дата, пробег, пожелания, диагностика, рекомендации, выполненная работа, стоимость, предоплата
- **Фото с комментариями** — drag & drop, автосжатие до 1280px
- **Поиск** по фамилии, гос. номеру, марке, телефону, дате визита
- **Печать** — карточка целиком или отдельный визит
- **Бэкап / восстановление** — JSON

Данные хранятся локально в браузере (IndexedDB). Никуда не отправляются.

## Стек

HTML + CSS + ES modules + IndexedDB. Шрифты: Fraunces, IBM Plex Sans, JetBrains Mono (через Google Fonts).
